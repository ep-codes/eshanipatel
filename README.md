# Eshani Patel Portfolio

A personal portfolio website designed to showcase my work across architecture, UI/UX design, graphic design, illustration, and content creation.

## About

This portfolio represents my approach to design as a multidisciplinary creative. As an architecture student with a background in computer science and a strong interest in visual design and technology, I enjoy exploring the connections between different creative disciplines.

The website is designed to make it easy for visitors to explore different types of work while maintaining a simple, friendly, and professional experience.

## Featured Areas
🏛️ Architecture — Studio projects, architectural design, research, and visualization.  
🖥️ UI/UX Design — Interfaces, digital experiences, wireframes, and prototypes.  
🎨 Graphic Design — Branding, layouts, visual communication, and graphics.  
✏️ Illustration — Digital and traditional artwork, including watercolor, gouache, and acrylic work.  
📱 Content Creation — Social media content, photography, video, and creative storytelling.  

## Design

The website uses a soft, pastel-inspired visual identity with shades of:

- Soft pink   
- Pastel blue  
- Pastel green  
- Soft purple  
- Warm white  
- Slate gray  

The overall design focuses on clarity, accessibility, simplicity, and personality, while allowing the projects themselves to remain the primary focus.

## Tech Stack

- HTML  
- CSS  
- JavaScript  
- Responsive Web Design  
- Git & GitHub  

## Goals

The portfolio is built to:

- Present multidisciplinary work in an organized way.  
- Make projects easy to discover and navigate.  
- Showcase both creative and technical skills.  
- Provide recruiters and collaborators with a quick understanding of my experience.  
- Create a portfolio that feels personal rather than like a standard template.
