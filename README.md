# Eshani Patel Portfolio — Pastel Editorial V2

This revision keeps the existing portfolio information while giving the homepage a much stronger visual identity: a warm pastel palette, oversized editorial typography, asymmetrical portrait treatment, floating labels, decorative shapes, and a more expressive project layout.

## Palette
Cream, rose, coral, lavender, butter yellow, sage, and powder blue are defined at the top of `styles.css`.

## Images
Add your portrait at `assets/profile-placeholder.jpg`. Replace the Project Image placeholders in `index.html` with your project images when ready.

## Run
Open `index.html` directly or use VS Code with Live Server.
